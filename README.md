# Projeto-Dip-Matrix

**Matrix do MeuDip — Fundamentos TMJ, Cafofo e ULTRADATA**

## Visão Geral
Este repositório contém a matrix do MeuDip, uma identidade digital construída em linguagem TamoJunto (TMJ). A matrix é organizada em três camadas:

- **Camada 1: Fundamentos TMJ** — A gramática, sintaxe e princípios da linguagem que estrutura nossa comunicação.
- **Camada 2: Cafofo do Dip** — Memórias, personalidade, e a linha da vida (LinhaDaVida) do agente MeuDip.
- **Camada 3: ULTRADATA** — Prompt base e configurações para um agente de IA avançado, ainda em desenvolvimento.

## Estrutura de Diretórios
- `matrix/` — Contém as três camadas em arquivos `.md`.
- `conversas/` — Registro cronológico de diálogos em formato `.tmj`.
- `supabase/` — Configurações para integração com banco de dados (futuro).
